# Phase 3F-R0 data-dictionary addendum

## Scope and historical boundary

This versioned addendum supplements the committed root `DATA_DICTIONARY.md` only for Phase 3F-R0. It does not replace, modify, supersede, or reinterpret that Phase 3E-R3-era dictionary. The root dictionary remains byte-pinned historical source evidence at SHA-256 `484c9a618076b3291756dcf47d551e50173a4394d6e43e0a826bcbe4c4a8582b`.

A changing documentation file cannot simultaneously retain its historical byte identity. The earlier requirement to place the Phase 3F-R0 inventory directly in the root dictionary is therefore waived only as to documentation location. This addendum supplies the versioned location. No data, schema, leakage, provenance, determinism, safety, or artifact-integrity requirement is waived.

The original ignored `curated/phase3f-r0/` namespace remains authoritative for the scientific construction. Phase 3F-R0.1 contains references and reconciliation metadata only; it is not a scientific rebuild. No R0.1 artifact may contain expanded-training rows, row-level targets, estimator-feature values, fitted preprocessing or estimator parameters, predictions, metrics, or final-test results. Generated artifacts in either namespace are ignored evidence and must not be committed.
